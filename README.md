# Joyner B's BBQ Website

Modern, responsive BBQ restaurant website with online ordering and catering request system.

## 🍖 Features

- **Hero Section** - Full-screen hero with parallax effect
- **Menu Showcase** - Visual menu cards with background images
- **Online Ordering** - Shopping cart system with localStorage persistence
- **Catering Form** - Overlay modal with EmailJS integration
- **Email Notifications** - Dual email system (caterer + customer confirmation)
- **Security** - Modern 2026 security standards (CSP, XSS prevention)
- **Responsive Design** - Mobile-friendly layout

## 🚀 Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- EmailJS for form submissions
- Google Fonts (Bebas Neue, Inter)
